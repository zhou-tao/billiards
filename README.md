# 🎱 极速台球 3D

一个纯前端、零构建的 3D 台球小游戏，基于 **Three.js** 渲染 + 自研轻量物理引擎，
带完整的**三维碰撞特效**：粒子火花、桌面冲击波、撞击闪光、镜头震动与实时合成音效。
支持三种模式：**单人街机** / **本地同屏双人** / **联机对战（自动匹配 + 游客观战）**。

## 🚀 运行方式

### 单人 / 本地双人
直接双击 `index.html` 即可（three.js 已本地化，无需联网）。

### 联机对战
```bash
cd billiards-3d
node server.js          # 需先 npm install（安装 ws）
```
服务器启动后会打印本机的局域网地址（如 `http://192.168.x.x:8250`）：

- 两台电脑各自用浏览器打开该地址 → 点击「🌐 联机对战」→ **自动匹配成对手**
- 第 3 个及之后打开的人自动进入 **游客观战视角**（仅观看，可旋转视角）
- 任一玩家离开 → 房间重置，自动等待新对手匹配

> 若无法连接，请检查防火墙是否放行 8250 端口。

## 🎮 操作说明

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 瞄准（辅助线预测第一碰撞点、目标球走向与白球分离方向） |

## 🎯 游戏模式

### 单人街机
- 每打进一球 **+100 分**；一杆多球有连击奖励（每额外一球 +50）
- 白球落袋为犯规：**-100 分**，白球重新摆回开球区
- 清空全部 15 颗彩球即胜利，结算得分 / 杆数 / 用时

### 双人对战（同屏八球）
- 双方自动分配随机搞笑昵称（哈基米 VS 汪汪队…），计分板实时显示分组、落袋与当前回合
- **开放球台**：首个合法落袋决定分组（全色 1-7 / 条纹 9-15）
- 进本组球 → 继续击球；空杆 / 白球落袋 / 首碰对方球 / 违规先碰黑八 → **犯规换人**
- 清完本组后可打黑八：合法打进黑八 **获胜**；提前进黑八或黑八时白球落袋 **直接判负**
- 开放球台阶段黑八落袋：不判胜负，重新摆回置球点

### 联机对战（局域网）
- 打开页面点击「联机对战」即自动连接并匹配，无需注册登录
- 自动分配**搞笑昵称**（哈基米、汪汪队、母球收藏家、袋口守门员…），房间内不重复
- **玩家1 = 房主（权威端）**：运行完整物理与规则，广播出杆快照与结算结果
- **玩家2**：本地瞄准出杆，指令交房主模拟执行；双方各自本地预测渲染，60fps 流畅
- **游客**：实时观战，可看到双方瞄准辅助线与力度，可自由旋转/缩放视角
- 出杆指令带回合校验；玩家离开自动重置房间等待重新匹配

## ✨ 三维碰撞特效

- **粒子火花**：碰撞点喷射金白炽热粒子（少量冷色碎片点缀），带重力、台面弹跳与加色淡出
- **冲击波光环**：桌面扩散的发光圆环，强度越大范围越大
- **撞击闪光**：碰撞点动态点光源脉冲，照亮球体与台呢
- **镜头震动**：重击与落袋时相机随机抖动并指数衰减
- **合成音效**：WebAudio 实时合成——球碰球脆响、库边闷响、落袋下滑音、出杆声、胜利琶音（零音频素材）

## 🔧 技术要点

```
billiards-3d/
├── server.js           ⭐ 联机服务器：静态托管 + WebSocket 房间匹配与消息中继
├── index.html          页面结构 + HUD + 模式选择 + 双人计分板 + 联机大厅
├── css/style.css       界面样式（玻璃拟态面板、力度条、计分板、联机大厅）
├── js/physics.js       物理引擎：积分摩擦、球-球弹性碰撞、库边反弹、袋口判定、瞄准射线预测
├── js/rules.js         八球规则引擎（纯逻辑、零依赖，可独立单元测试）
├── js/net.js           联机客户端：WebSocket 封装与事件分发
├── js/effects.js       特效系统：粒子池、冲击波环池、撞击光源、镜头震动
├── js/audio.js         WebAudio 合成音效（含节流防爆音）
├── js/game.js          主程序：场景搭建、球杆/辅助线、交互、摄像机、三种模式与结算
├── lib/three.min.js    Three.js r149（本地化，可离线）
└── test-server.js      服务器自动化测试（18 项断言）
```

- 物理：固定步长 1/360s 子步积分，等质量弹性碰撞（恢复系数 0.93），库边反弹 0.76，
  滚动摩擦 + 指数阻尼，袋口区域取消库边反弹实现"滑入落袋"
- 规则：`rules.js` 与渲染完全解耦，`resolve()` 输入一杆结果、输出胜负/犯规/轮换裁决，
  已通过 19 项决策表单元测试 + 无头全链路集成测试
- 球体数字贴图由 Canvas 2D 实时绘制（全色球 / 条纹球 / 带红点的白球），球体按位移做真实滚动旋转
- 想调手感？改 `js/physics.js` 顶部的常量：`FRICTION_A`、`RESTITUTION_BALL`、
  `RESTITUTION_CUSHION`、`POCKETS` 的 `r`（袋口松紧）；出杆力度上限 `MAX_SHOT_SPEED` 在 game.js
